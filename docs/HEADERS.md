# include/ header index

Generated by `build/agents/types1/scan/headers_index.py` (descriptions in `headers_desc.py`).
One row per header: what it provides, the macro/type names to use, how many src files include it,
and one example user (for brand-new headers: a check_match proof copy under build/agents/types1/proof).
Grep this file before writing a local struct/typedef: `Select-String docs\HEADERS.md -Pattern <field|callee|class>`.

Rules of thumb:
- Include `script_arg.h` before any `*_types.h` that also defines `ScriptArg` (first definition wins).
- Headers with prototypes take `void*` params; delete conflicting local `extern` declarations,
  or `#define <NAME>_NO_PROTOS` before the include and keep your own typed ones.
- C++-only headers (`cnpc_vslots.h`, `gui_widget_vslots.h`, `vslot_*`, `*_dtor.h` with classes) need `#pragma cplusplus on` / a .cpp unit.
- Do not edit headers in ways that change layout or macros; matched src depends on them.
